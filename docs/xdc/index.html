How It Works

  • Upload a .xdc game file (webxdc format)
  • Game runs in a secure sandboxed iframe
  • Virtual gamepad appears automatically on mobile
  • Progress saved locally in your browser (IndexedDB)

Features

🎮

Adaptive Virtual Gamepad

Automatically switches between overlay, sidebar, and below layouts based on game aspect ratio

💾

Local Save/Load

Game progress saved to IndexedDB — persists across sessions, works offline

📱

Responsive Layouts

Widescreen games get bottom overlay; square games get side controls; portrait gets bottom bar

🔒

Privacy First

No server uploads — everything runs client-side. Your games, your data.

Browser Compatibility

Requires modern browser with Service Worker and IndexedDB support

  • ✅ Chrome 80+ / Edge 80+
  • ✅ Firefox 75+
  • ✅ Safari 14+ (iOS 14+)
  • ✅ Samsung Internet 13+
  • ⚠️ Requires Service Worker & IndexedDB support
