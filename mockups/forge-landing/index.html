// What We Build

📻livepython

Icepick

The heart of the station. A custom Python scheduler that picks tracks, crossfades on the fly, and pushes the stream to Icecast. Schedules, playlists, shotgun mode, full dashboard. No LiquidSoap, no black boxes.

🎛️activepython

CastileSoap

The DJ engine — it takes orders from AI. Auto-DJ with a FastMCP server handing the full schedule, playlists, and playback controls to LLM clients. You don't just run the station, you can talk to it.

🔁activepython

Icetray

The relay tier, decentralized. Lightweight cubes anyone can run — pull the parent stream, re-serve to local listeners, spread load, cut distance. One dependency, Pi-class friendly.

🤖activetypescript

WOPR

AI-powered Revolt bot with an OpenWebUI brain and a kill switch wired to health checks — when the brain goes down, it knows before you do.

⚡activetypescript

H4X

An OpenCode-powered AI coding assistant living in your chat. Multi-model, code execution, file management — a dev environment that answers when called.

🐱alphatypescript

The Catalyst

MRX tipbot with a full HD wallet, Cat Creds rating system, and gamified crypto lifecycle tiers. Crypto with personality.

🔗activepython

Matrix-Bridge

Multi-platform message bridge — Revolt, Discord, Matrix, Fluxer, Telegram — with file uploads, webhooks, and content filtering. One conversation, every room.

📊activebash

Kener

Self-hosted status page with a dual-tunnel watchdog. Monitors the whole ZamRock infrastructure and recovers itself when something blinks.
