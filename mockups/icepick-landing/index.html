What We Built

A radio stack that actually listens to you.

📻

Icepick — the engine

Pure Python, async everything. SQLite data, direct Icecast push. Runs on a $5 VPS or a Raspberry Pi without breaking a sweat. Schedule-aware picking with playlist weights and genre rules. Shotgun DJ mode pairs every pick with a same-album buddy.

🎛️

CastileSoap — the brain

Multi-station dashboard, AI-powered AutoDJ that learns listener patterns and adapts in real time, with a simple random fallback if the smart layer goes down. Native MCP server: manage schedules through any MCP client.

🔁

Icetray — the relay

Fetch once, broadcast many. Relay cubes re-encode one source into any number of streams — bitrates, formats, caps. Smart load balancing moves heavy listeners to nearest relays. Fallback chains mean the music never stops.

🗺️

Listener Geo Map

Real-time tracking with city-level resolution. Session history, CSV imports, time-range analysis. Know your audience.

⚡

Instant Restart

Reboots pick up exactly where they left off — same track, same queue, same plan. No dead air, no confused listeners.

🔇

Never Silence

Fallback chains keep music playing if a relay drops — automatic failover with zero listener interruption. Private by default: relays sit behind Cloudflare proxies, IPs sanitized.
